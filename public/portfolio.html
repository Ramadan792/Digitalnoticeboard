Overview

What it does

One login portal, two kinds of accounts, and a moderation queue in between — so nothing reaches the board without a Main Admin's sign-off.

Every visitor lands on a single portal and chooses Student or Admin. Students submit announcements that start out pending. Admins can view every submission, but only the Main Admin can approve, reject, or delete — the other two admins get the same data in a read-only table. Approve, reject, and delete all update the screen instantly, without waiting on a server round-trip, and the whole interface supports light and dark mode.

Roles & permissions

Who can do what

Student
  • Signs in with a Student ID only — no password
  • Submits new announcements for review
  • Browses the approved daily news feed
  • Has no access to admin pages
Admin
  • Signs in with a name and shared admin password
  • Mrs. Okoro & Mr. Bello: view-only access to all submissions
  • Main Admin: can also approve, reject, and delete
  • Approve/reject/delete update the screen instantly
Tech stack

Built with

Frontend

React 18 + Vite, React Router v6 for routing.

Styling

Plain CSS with custom properties — one token set drives both light and dark themes.

Backend

Node.js / Express, deployed as Vercel Serverless Functions.

Data

Redis (Upstash) via @vercel/kv — persists reliably across serverless instances.

Icons

lucide-react.

Hosting

Vercel, connected to GitHub for auto-deploy on every push.
